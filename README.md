# Predicting Customer Churn at QWE Inc.

## Descripción del proyecto

Este repositorio contiene el análisis de datos del caso *Predicting Customer Churn at QWE Inc.*, desarrollado para la asignatura Analítica de los Negocios de la Pontificia Universidad Javeriana.

El caso estudia el abandono de clientes de QWE Inc., una empresa que ofrece servicios por suscripción a pequeñas y medianas empresas.

## Objetivo

Analizar las características de los clientes para identificar los factores asociados con su abandono y construir un modelo que permita estimar la probabilidad de cancelación durante los próximos dos meses.

Adicionalmente, se busca identificar los 100 clientes con mayor riesgo de abandono y proponer recomendaciones para mejorar las estrategias de retención.

## Herramientas

- R
- tidyverse
- ggplot2
- readxl
- GitHub

## Contenido del repositorio

El repositorio incluirá la base de datos del caso, el código desarrollado en R, las tablas y gráficas generadas y el informe final con los resultados del análisis.

## Integrantes

Trabajo desarrollado por un equipo de tres estudiantes de Administración de Empresas de la Pontificia Universidad Javeriana.
